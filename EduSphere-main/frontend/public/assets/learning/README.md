# Illustrated game assets

The contributor supplied EduSphere mockups on 13 November 2026 and requested ImageGen artwork. The latest instruction retains the existing app UI and focuses on gameplay. Only subject illustrations remain in the application; the island map, decorative guide and interface atlas have been removed.

- `biology-atlas.webp`: 4 columns × 3 rows, 12 biology illustrations.
- `horizontal-battery.webp`: compact ATP battery; live HTML supplies its label.
- `imagegen-prompts.json`: historical generation prompts, including assets no longer shipped. PNG originals remain in the local ImageGen output directory.

Transparent output was requested and checked; the biology atlas background was removed with a second ImageGen edit. WebPs preserve the original alpha. CSS background positioning samples the artwork; text, controls, ports and dynamic connection paths remain accessible UI.

The artwork is static bitmap material. Rive authoring and integration are deferred.
